题目大意

有 222 个长度为 NNN 的数组 AAA 和 BBB，可以任意排列 BBB 数组，求出一个非负整数 xxx，满足：

Ai⊕Bi′=xA_i \oplus B'_i = x Ai​⊕Bi′​=x

此处 ⊕\oplus⊕ 表示异或，B′B'B′ 为重新排列后的 BBB。

找出所有 xxx 并按照从小到大输出。

意外发现

在正解之前，我先说一下我和 @naijil 在考场上的意外发现。

在 NNN 为奇数时，如果存在 xxx 使得：

Ai⊕Bi′=xA_i \oplus B'_i = x Ai​⊕Bi′​=x

那么就有：

(A1⊕B1′)⊕(A2⊕B2′)⊕⋯⊕(AN⊕BN′)=x⊕x⊕⋯⊕x(A1⊕B1′)⊕(A2⊕B2′)⊕⋯⊕(AN⊕BN′)=x(A1⊕A2⊕⋯⊕AN)⊕(B1′⊕B2′⊕⋯⊕BN′)=x(A1⊕A2⊕⋯⊕AN)⊕(B1⊕B2⊕⋯⊕BN)=x\begin{align*} (A_1 \oplus B'_1) \oplus (A_2 \oplus B'_2) \oplus \dots \oplus (A_N \oplus B'_N) &= x \oplus x \oplus \dots \oplus x \\ (A_1 \oplus B'_1) \oplus (A_2 \oplus B'_2) \oplus \dots \oplus (A_N \oplus B'_N) &= x \\ (A_1 \oplus A_2 \oplus \dots \oplus A_N) \oplus (B'_1 \oplus B'_2 \oplus \dots \oplus B'_N) &= x \\ (A_1 \oplus A_2 \oplus \dots \oplus A_N) \oplus (B_1 \oplus B_2 \oplus \dots \oplus B_N) &= x \\ \end{align*} (A1​⊕B1′​)⊕(A2​⊕B2′​)⊕⋯⊕(AN​⊕BN′​)(A1​⊕B1′​)⊕(A2​⊕B2′​)⊕⋯⊕(AN​⊕BN′​)(A1​⊕A2​⊕⋯⊕AN​)⊕(B1′​⊕B2′​⊕⋯⊕BN′​)(A1​⊕A2​⊕⋯⊕AN​)⊕(B1​⊕B2​⊕⋯⊕BN​)​=x⊕x⊕⋯⊕x=x=x=x​

这也证明了在 NNN 为奇数时 xxx 不超过 111 个。

但是这个 xxx 不一定存在，所以需要判断一下，然后就骗了 505050 分。

正解

找出候选

首先观察 A1A_1A1​，他最终匹配到的 B1′B'_1B1′​ 一定是某一个 BjB_jBj​，即：

A1⊕Bj=xA_1 \oplus B_j = x A1​⊕Bj​=x

所以 xxx 只有 nnn 种可能：

{A1⊕B1,A1⊕B2,…,A1⊕BN}\{A_1 \oplus B_1, A_1 \oplus B_2, \dots, A_1 \oplus B_N\} {A1​⊕B1​,A1​⊕B2​,…,A1​⊕BN​}

验证候选

如何验证候选呢？

首先我们注意到一个异或的性质，当

a⊕b=xa \oplus b = x a⊕b=x

成立，就有：

a⊕x=bb⊕x=aa \oplus x = b \\ b \oplus x = a \\ a⊕x=bb⊕x=a

所以对于候选 xxx，一定有一个排列后的 B′B'B′：

Bi′=Ai⊕xB'_i = A_i \oplus x Bi′​=Ai​⊕x

然后判断

{ ⁣{Bi′} ⁣}={ ⁣{Bi} ⁣}\{\!\{ B'_i \}\!\} = \{\!\{ B_i \}\!\} {{Bi′​}}={{Bi​}}

是否成立即可，如果成立就选择当前候选 xxx 加入答案列表。

具体在代码中可以使用排序判断 B′B'B′ 与 BBB 是否相同。
