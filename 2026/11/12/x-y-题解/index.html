x:y 题解

原题目

x:y

  • OJ PID：P5127
  • 时空限制：1000ms / 256MiB

题目描述

给定两个序列 a1,a2,…,ana_1,a_2,\ldots,a_na1​,a2​,…,an​ 和 b1,b2,…,bmb_1,b_2,\ldots,b_mb1​,b2​,…,bm​。

请你确定一个整数 ddd，然后对 a,ba,ba,b 两个序列分别计算分数。序列的分数计算方式如下：序列中每有一个数字大于等于 ddd 记 333 分，每有一个数字小于 ddd 记 222 分。

你需要使得序列 aaa 与序列 bbb 的分数之差最大。

输入格式

第一行输入一个整数 nnn。

第二行输入 nnn 个整数 a1,a2,…,ana_1,a_2,\ldots,a_na1​,a2​,…,an​。

第三行输入一个整数 mmm。

第四行输入 mmm 个整数 b1,b2,…,bmb_1,b_2,\ldots,b_mb1​,b2​,…,bm​。

输出格式

输出形式为 x:y，其中 xxx 表示序列 aaa 的分数，yyy 表示序列 bbb 的分数。需要使得 x−yx-yx−y 尽可能大；若有多种答案，输出 xxx 最大的那个。

样例输入 1

样例输出 1

样例输入 2

样例输出 2

数据范围

对于 20%20\%20% 的数据，保证 ai,bi≤1000a_i,b_i\le 1000ai​,bi​≤1000。

对于另外 20%20\%20% 的数据，保证 ai,bi≤106a_i,b_i\le 10^6ai​,bi​≤106。

对于另外 20%20\%20% 的数据，保证 n,m≤1000n,m\le 1000n,m≤1000。

对于 100%100\%100% 的数据，保证 1≤n,m≤2×1051\le n,m\le 2\times 10^51≤n,m≤2×105，1≤ai,bi≤2×1091\le a_i,b_i\le 2\times 10^91≤ai​,bi​≤2×109。

题目大意

给定长度为 nnn 的序列 aaa 和长度为 mmm 的序列 bbb。选择一个整数 ddd，对两个序列分别计分：序列中每个 ≥d\ge d≥d 的数记 333 分，每个 <d<d<d 的数记 222 分。设序列 aaa 的得分为 xxx，序列 bbb 的得分为 yyy，要求最大化 x−yx-yx−y；若有多组方案达到最大值，输出 xxx 最大的那一组，格式为 x:y。

题目分析

PART A

注意到：每个数至少得 222 分，只有额外 111 分取决于该数是否 ≥d\ge d≥d。因此：

x=n×2+∑i=1n[ ai≥d ]x = n \times 2 + \sum_{i=1}^{n}\left[\,a_i \ge d\,\right] x=n×2+i=1∑n​[ai​≥d]

y=m×2+∑j=1m[ bj≥d ]y = m \times 2 + \sum_{j=1}^{m}\left[\,b_j \ge d\,\right] y=m×2+j=1∑m​[bj​≥d]

PART B

ddd 只需考虑 a,ba,ba,b 中出现过的值，共有 n+mn+mn+m 种可能。将数组 aaa 和 bbb 均升序排序，并使用类似归并排序的方式将 aaa 和 bbb 交错，可得到类似如下的内容：

aaa 111 666 202020 272727
bbb 333 555 777 101010 171717

此时 ddd 可以取：1,3,5,6,⋯ ,271,3,5,6,\cdots,271,3,5,6,⋯,27。

使用两个指针 p1,p2p1,p2p1,p2 遍历数组 a,ba,ba,b，每次取当前最小值作为 ddd。

对于每一个 ddd，可求出各数组中有多少个数 ≥d\ge d≥d：数组 aaa 为 n−p1+1n-p1+1n−p1+1，数组 bbb 为 m−p2+1m-p2+1m−p2+1。再计算当前 ddd 对应的得分差 x−yx-yx−y，取最大值作为最终答案。

时间复杂度分析

读入：

O(n+m)\mathcal{O}(n + m) O(n+m)

排序：

O(nlog⁡n+mlog⁡m)\mathcal{O}(n \log n + m \log m) O(nlogn+mlogm)

双指针遍历：

O(n+m)\mathcal{O}(n + m) O(n+m)

总时间复杂度：

O(nlog⁡n+mlog⁡m)\mathcal{O}(n \log n + m \log m) O(nlogn+mlogm)
